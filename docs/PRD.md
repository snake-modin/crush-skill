# crush.skill — 产品需求文档（PRD）

## 产品定位

`crush.skill` 是一个运行在 Claude Code 上的 meta-skill。
用户输入对暗恋对象的观察、互动记录和公开材料，系统生成一个可独立运行的 crush Persona Skill，用于**聊天排练、邀约预演、表白预演和自我校准**。

## 目标用户

- 想约暗恋对象吃饭，但怕一开口就尴尬的人
- 想表白，但不确定说法是否太冒进的人
- 对对方有明显好感，想先在低风险环境里练习的人
- 容易把少量信号放大，想做现实校准的人

## 核心原则

1. **用于排练，不用于预测**
2. **用于整理证据，不用于脑补结果**
3. **不鼓励操控、跟踪、试探性伤害**
4. **所有数据默认本地保存**
5. **材料不足时，宁可保守，不做甜蜜幻觉**

## 核心结构

### Part A: Interaction Memory

存储与暗恋对象有关的互动事实：
- 怎么认识
- 当前关系阶段
- 已发生过的聊天与见面
- 共同话题和共同朋友
- 适合邀约的切口
- 明确边界与不确定点

### Part B: Persona

驱动对话表现：
- 说话风格
- 回复节奏
- 主动程度
- 面对邀请的倾向
- 面对表白时的反应方式

## 典型用户流程

```text
用户触发 /create-crush
  -> 输入代号、阶段、印象
  -> 导入聊天/截图/照片/手写描述
  -> 系统分析 Interaction Memory + Persona
  -> 生成预览
  -> 写入 .claude/skills/{slug}/
  -> 用户通过 /{slug} 开始排练
```

## 关键场景

### 1. 约饭预演
用户输入不同版本的邀请方式，Skill 按当前关系阶段做更贴近现实的回应。

### 2. 表白预演
用户测试告白强度，Skill 根据材料判断对方更可能是接受、含糊、回避还是拒绝。

### 3. 开场聊天热身
用户先在 Skill 中练几轮，找出太冷、太黏、太突然的表达。

### 4. 增量进化
用户补充新的聊天截图或见面细节，Skill 更新互动判断。

## 安全边界

- 不把模拟结果包装成现实承诺
- 不建议用户通过欺骗、试探、PUA 等方式推进关系
- 不鼓励把一个人长期困在幻想版本里
- 不主动替用户联系真人
