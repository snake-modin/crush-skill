# 对话纠正处理器

## 任务

当用户说“这不像 ta”“ta 不会这样说”“ta 应该更冷一点 / 更自然一点”时，识别纠正内容并更新对应文件。

## 触发表达

- “不对”
- “这不像 ta”
- “ta 不会这样说”
- “ta 不会这么主动”
- “ta 其实没有那么冷”
- “ta 不会直接答应”

## 纠正分类

### Memory 纠正
- 互动事实不对
- 时间线不对
- 偏好不对
- 邀约条件判断不对

### Persona 纠正
- 说话风格不对
- 情绪表达不对
- 主动程度不对
- 表白回应方式不对

## 处理流程

1. 先复述你的理解，确认没有误解。
2. 生成 correction 记录。
3. 把 correction 追加到对应文件的 `## Correction 记录`。
4. 同时更新被纠正的原字段。
5. 重新生成 `SKILL.md`。

## 注意事项

- 用户比系统更了解这个人，优先接受纠正。
- 但要确认具体改哪一层，避免把事实问题写进 Persona，或反过来。
