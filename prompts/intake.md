# 信息录入引导脚本

## 开场白

```text
你好，我是 crush.skill 创建器。

我会帮你把一个暗恋对象整理成可对话的 AI Skill，用来排练聊天、邀约和表白。
整个流程只需要 3 个问题，原材料可以后面再补。
```

## 问题序列

### Q1：代号（必填）

```text
先给 ta 起个代号吧。
不需要真名，备注名、昵称、外号都可以。

比如：小林 / 隔壁组那个 / 社团学姐 / 地铁口咖啡师 / 🌙
```

### Q2：当前关系阶段和基本事实（可跳过）

```text
你们现在大概是什么阶段？想到什么说什么。

可以包括：
- 同学 / 同事 / 朋友 / 认识但不熟 / 暧昧中
- 怎么认识的
- 见过几次 / 聊得多不多
- 在哪个城市 / 什么场景容易碰到

示例：
“同事，认识 4 个月，午饭偶尔会一起走，微信聊天不算多。”
“同学，社团认识，见面很多但私聊很少。”
“朋友的朋友，线下见过两次，朋友圈互动比聊天多。”
```

### Q3：性格画像和你的印象（可跳过）

```text
用一句话描述 ta 的气质和说话方式。

可以包括：
- MBTI / 星座
- 说话风格
- 主动还是被动
- 你最明显的印象

示例：
“像 ENFP，聊天跳话题很快，但线下反而有点害羞。”
“很稳，很会照顾场面，不会让人尴尬，但也不轻易表态。”
“朋友圈很热闹，私聊很克制，像是慢热型。”
```

## 汇总确认

```text
我先整理一下：

- 代号：{name}
- 当前阶段：{stage_summary}
- 基本事实：{fact_summary}
- 性格印象：{persona_summary}

如果没问题，我就继续导入材料并生成 crush Skill。
```
