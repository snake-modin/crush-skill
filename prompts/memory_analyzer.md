# Interaction Memory 分析器

## 任务

从原材料中提取与暗恋对象有关的**互动事实**，构建 Interaction Memory。
重点是“你知道什么、你们发生过什么、哪些地方仍然不确定”。

## 提取维度

### 1. 关系起点
- 怎么认识的
- 认识多久了
- 当前阶段（陌生 / 认识 / 熟人 / 朋友 / 暧昧中）
- 谁更主动

### 2. 互动节奏
- 聊天频率和活跃时段
- 线下见面频率
- 谁先开话题
- ta 会不会主动延续话题

### 3. 共同场景
- 常见面的地点
- 一起做过的事
- 共同朋友 / 共同圈层
- 反复出现的话题

### 4. 已知偏好
- 食物、咖啡、电影、音乐、游戏、运动
- 喜欢去的地方
- 公开表达过的偏好
- 你亲眼观察到的习惯

### 5. 正向信号
- 主动找你聊天
- 愿意单独见面
- 会记得你说过的话
- 会接你的梗或延续话题

### 6. 保留和边界
- 明显回避的话题
- 拒绝过什么
- 对亲密推进是否敏感
- 有没有把你稳定放在“朋友 / 同事”位置上

### 7. 邀约线索
- 什么类型的邀请更自然
- 哪些切口最不突兀
- ta 更容易接受一对一还是多人局
- 时间、地点、节奏上的偏好

### 8. 表白风险点
- 现在关系是否太浅
- 是否有明显暧昧迹象
- 是否已有对象或明确边界
- 哪些表达会显得太突然

## 输出格式

```markdown
## 当前阶段
- 阶段：{stage}
- 置信度：{high/medium/low}
- 依据：{evidence}

## 时间线
- {date}: {event}

## 互动节奏
{summary}

## 共同场景与话题
{summary}

## 已知偏好
{summary}

## 正向信号
{summary}

## 边界与保留
{summary}

## 邀约建议线索
{summary}

## 表白风险点
{summary}

## 未知项
{summary}
```

## 注意事项

- 把“事实”和“推测”分开写。
- 没证据的地方标记为未知，不要补成甜蜜剧情。
- 同一材料里反复出现的模式，优先级高于一次性片段。
