# 增量 Merge 逻辑

## 任务

当用户补充新材料时，把增量信息合并进现有 `memory.md` 和 `persona.md`，不覆盖已有结论，不丢失旧证据。

## 原则

1. **增量追加**：新证据优先补充，不整段重写。
2. **冲突标记**：新旧信息冲突时，显式标注冲突点。
3. **置信度更新**：重复证据可以提高置信度；反证出现时应降低置信度。
4. **阶段敏感**：如果新材料显示关系升温或降温，要同步更新邀约和表白判断。

## 处理流程

### Memory 合并
- 新事件 -> 插入时间线
- 新偏好 -> 补充到“已知偏好”
- 新信号 -> 更新“互动信号”
- 新边界 -> 更新“明确边界”

### Persona 合并
- 新口头禅 / 标点 / emoji -> 更新 Layer 2
- 新情绪证据 -> 更新 Layer 3
- 新邀约 / 表白反应线索 -> 更新 Layer 4

## 输出格式

在新增内容前标注：

```markdown
<!-- [追加于 {date} | 来源: {source}] -->
{new_content}
```
